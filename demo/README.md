These three demo scripts demonstrate the three key flows shown in the pitch video. Run `demo_blocked.py` to see a disputed invoice correctly blocked with zero customer contact. Run `demo_api_failure.py` to see graceful API failure handling with full audit logging. Run `demo_recovery.py` to see a successful end-to-end recovery — a new Razorpay payment link is created in test mode and the browser opens for you to complete a test payment using card 4111 1111 1111 1111.
